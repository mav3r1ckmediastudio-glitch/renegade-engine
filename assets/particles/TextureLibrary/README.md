# Particle texture starter collection

50 curated entries: 40 selected static images from the owner-supplied Particles archive and 10 supplied textures/sheets. Original image bytes are preserved. catalog.json records source filenames, SHA256, atlas layout, playback and recommended blending. The ember atlas intentionally uses only cell 3 (zero based); the other masks are not animation frames. The original file Embers.png is the flame sheet. Installed files are adopted into governed project texture assets on first use. No redistribution or release gate is asserted by this local candidate.
