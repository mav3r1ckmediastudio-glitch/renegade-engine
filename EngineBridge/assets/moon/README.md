# Lunar albedo source

Unmodified NASA Scientific Visualization Studio CGI Moon Kit 2025 colour-map JPEG.

- Source page: https://svs.gsfc.nasa.gov/4720/
- Asset: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg
- Credit: NASA's Scientific Visualization Studio. Visualization: Ernie Wright (USRA);
  scientist: Noah Petro (NASA/GSFC). Colour map derives from LRO/LROC WAC data.
- Dimensions: 2048 x 1024; 457942 bytes.
- SHA-256: f7130a1822681fa7512d7dcfd40db8c10b9ba4f06777910348698260ed7a2170

The source page supplies these maps for 3D rendering. This file contains no NASA
logo or insignia; Renegade does not imply NASA endorsement. Preserve this source
credit with redistributions. NASA media guidance:
https://www.nasa.gov/nasa-brand-center/images-and-media/

EngineBridge CMake generates a byte-array include from this JPEG and links it
into Studio, Runtime and the explicit GPU proof. One map supplies every phase.
No external download or loose asset is required when the application runs.
