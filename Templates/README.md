# Templates and examples

Starter/template integration area. Project creation consumes the installed starter
scene through ProjectService; a complete Blank/First-person/Third-person template
gallery is not established by the existence of this folder.

Generated proof projects, owner castle assets, marketplace scenes and private
acceptance packages are not redistributable templates. Any future shipped example
must include its complete dependency closure, source/resource provenance and
actual scene/reopen/Runtime verification.
