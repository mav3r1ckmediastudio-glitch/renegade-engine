Open Add > Particle, choose a layer, then Browse textures / sheets. The native browser provides Included and Project tabs, search, categories, static/animated filters, a thumbnail size control and paging. The initial grid shows twenty textures; smaller thumbnails show up to thirty-five. The right preview animates sheets and shows atlas settings before use. Cancel leaves the layer unchanged. Use texture changes only that layer's image, atlas and optional recommended blend; movement, fields, lifetime and size remain authored.

The included catalog contains exactly fifty entries: forty-two static images/maps and eight animated sheets. It includes the owner's candle, flame, smoke, steam, mist, three leaves, ember atlas and heat distortion normal. Original image bytes and source names are retained with SHA256 values in catalog.json. The original torch ember atlas is held on cell 3 of its 2x2 grid rather than animating unrelated masks. The heat map targets the material normal slot and native distortion shading.

Images are adopted into the project using CreatorTextureWorkflowService and normal governed texture products. Project texture profiles are transaction-backed, project-identity-checked authoring metadata at Content/Particles/TextureProfiles.rparticle-textures, keyed by existing asset IDs. They do not replace AssetRegistry authority. First use imports; later use reuses the existing governed product even when the installed source is absent. Only selected products enter project dependency closure. No catalog reads or whole-scene inventories occur in the frame loop.

Selecting a placed effect retains the usual name and transform inspector plus Edit Effect. Emitter and layer authoring belongs in the picker. Legacy standalone emitters also open there. ParticleEffectMarkerService visits only emitter components, resolves composite roots with direct lookups, and returns one marker per effect. Stock icon staging follows the actual Studio executable directory; a procedural fallback preserves selection if artwork is unavailable.
