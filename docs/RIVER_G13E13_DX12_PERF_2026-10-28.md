## Measurement design
- Controlled 1280×720 Renegade Runtime Release DX12 with the **actual combined** G13E11 native WISCENE, one authored waterfall, one G11 spline river, 25 resident terrain chunks, linked carved riverbed, whitewater source and 19 waterfall effect emitters.
- Real `wi::Application::Run()` and graphics-frame counter; 120 warm-up frames then timed wall-clock host graphics-loop intervals, up to 3600 measured frames. A separate DXGI `IDXGIAdapter3::QueryVideoMemoryInfo(DXGI_MEMORY_SEGMENT_GROUP_LOCAL)` on the Nvidia dedicated adapter samples local **process** video-memory usage every 30 frames. This is not GPU execution time, not a VRAM allocation profiler by resource, and not a full game with a moving player and physics/NPCs. Exactly 75 FPS-equivalent may be VSync or monitor refresh limiting; do not claim GPU headroom or uncapped FPS.
- Test-only environmental switches `RENEGADE_G13E13_PERF_CSV` (enables profiler/output), `RENEGADE_G13E13_FRAMES` (bounded 180–3600), `RENEGADE_WATERFALL_RUNTIME_PROOF` (inspection camera), `RENEGADE_G13E13_CAMERA_MOTION` (gentle bounded orbit) and `RENEGADE_G13E13_NO_SCREENSHOT` (excludes diagnostic file-write hitch). In normal Runtime launches without these variables, profiler opens no DXGI adapter, writes no file and does not move camera. A profile finishes with regular Runtime shutdown.
- Source `Runtime/src/RuntimeG13E13Perf.h`, opt-in hook in `Runtime/src/main_Windows.cpp`, opt-in diagnostic camera in existing `Runtime/src/RuntimeApplication.cpp`. Release build `BUILD/G13E13/build-perf-no-screenshot.exit=0`. This is not a gameplay/render shader change.
