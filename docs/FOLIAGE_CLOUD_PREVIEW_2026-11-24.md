The lower image region (x=0..1279, y=480..799) changes by mean absolute RGB about (85.19,80.07,56.98)/255 between daytime shadow on/off. The nighttime comparison changes only about (0.108,0.082,0.057)/255, consistent with low-level GI/dither variation rather than useful aligned lunar cloud shadows. These are display-pixel differences, not physical radiance. Native images were inspected.

The current renderer creates its one cloud-shadow projection from Weather sunDirection. The cloud-shadow compute shader uses GetSunDirection(), while the directional-light shader applies that map to shadow-receiving surfaces. The night scene's separate authored moonlight therefore does not receive a physically aligned lunar cloud projection. Cloud cover is visible at night, but moonlight cloud occlusion needs a separate renderer improvement. No shader/upstream patch was made for this preview, and the owner was told this limitation before it was opened.
