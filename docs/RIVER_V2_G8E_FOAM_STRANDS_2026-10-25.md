## Bounded implementation

New EngineBridge/shaders/RiverFoamStrandsCS.hlsl transports a source-born scalar occupancy tracer in a fixed1024x512 field. Three R32_FLOAT textures (two history plus forward scratch) cost6MiB. Two-pass MacCormack correction, with departure-stencil extrema limiting and [0,1] bounds, reduces thin-feature smearing. Midpoint backtracing samples the actual accepted velocity field; wet checks prevent departures through excluded native cells. Detail steps <=0.025s; normal75Hz live frames use two dispatches. Slow/test frames subdivide. No CPU mesh upload, geometry scan or domain rebuild per frame.

The tracer is an appearance/occupancy field, NOT a conserved foam mass or a replacement discharge solver. Narrow coherent structures are born only where existing enabled source channels inject foam. Their source labels vary smoothly; outside sources the structures are transported rather than scrolling a world-space pattern. Accepted finite-volume density/age/source/velocity/decay shaders and CPU domain remain byte-exact. Density always gates appearance; no detail field can emit foam independently. Source-off expiry and zero flow leave zero detail when the parent density expires.

Tools/prepare_river_strands_shading.py stages a separate native WATER pixel variant. It reads transported concentration directly, with soft coverage and boundary damping, and retains denser young froth locally. Small surface-wave geometry/normals and native WATER lighting/reflection/refraction/transparency remain the existing G8D code. New detail does not create overlay meshes, depth collars or particles. No Unreal assets/code copied. First isocontour iteration was visually rejected internally: hard cartographic lines and boundary outlines overrode numeric PASS. It was replaced with source-born occupancy transport and direct soft shading. Rejected shader snapshots remain in BUILD only and are not deployed.

Tools/prepare_river_strands_graphics_proof.py generates an optional derivative of the full native rapids/surface proof; Tests/CMakeLists.txt appends RenegadeRiverFoamStrandsProof only. Material raw-buffer prefix96B preserved, with16B extra detail descriptors; upper userdata state bit selects detail ping-pong while low bit retains exact bulk-state meaning. Detail textures/clock retained across native/appearance/wave switches; clear recreates them only for explicit reset. Default amount0.3 follows owner preference. No Studio/Runtime deployment, profile format or owner project change.
