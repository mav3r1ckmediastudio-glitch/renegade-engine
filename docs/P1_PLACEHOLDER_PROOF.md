## Repeatable fixture

Tests/PlayerViewRigFixture.cpp generates a WISCENE with an unassigned Player
Start at (0,2,0), a static box floor at Y=-0.5, baked visual floor dimensions
matching explicit collider half-extents (50,0.5,50), sky colours, ambient/sun
lighting and landmarks at Z=8. It saves and reloads the scene and checks that
one Player Start resolves with an empty arms assignment.

The generator requires Windows and a graphics device. It is an optional manual
build target, not an automatically registered CTest or interactive acceptance test.
It writes the supplied output scene path; use a disposable output.

From repository root:

```text
cmake -S . -B BUILD/renegade
cmake --build BUILD/renegade --config Release --target RenegadePlayerViewRigFixture -- /m:2 /verbosity:quiet /p:BuildProjectReferences=false
BUILD/renegade/Tests/Release/RenegadePlayerViewRigFixture.exe BUILD/renegade/p1-placeholder-proof/runtime-proof.wiscene
BUILD/renegade/Runtime/Release/RenegadeRuntime.exe --project BUILD/renegade/p1-placeholder-proof/RuntimeProof.renegade
```

The existing disposable descriptor directly selects runtime-proof.wiscene and
leaves startup_flow_id/startup_flow empty. Its governed GameplayInput file is
under Content/Data. This working project remains ignored under BUILD.
For another project, point its startup scene to the generated WISCENE and leave
arms unassigned. Do not copy an old Story Flow that silently selects another scene.

## Directional movement stutter: camera interpolation repair

The owner refined acceptance: other placeholder checks work, but directional
movement makes the proxies stutter. The camera sampled raw Jolt position while
the parented rig inherited Wicked's interpolated scene transform. The camera
now prefers the Player scene transform after Scene::Update; raw physics position
is retained only when that transform is missing.

The manual native fixture now runs 300 frames at 75 Hz scene updates and 120 Hz
physics, first settling and then walking forward/backward and sprinting sideways.
It compares camera Eye with rig root every frame and requires actual divergence
between raw physics and rendered Player positions, so a non-interpolating run
cannot silently pass. Authored fixture serialization occurs before this test.
