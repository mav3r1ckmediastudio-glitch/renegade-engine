# Whole-scene SHOW view modes

See ../../WIREFRAME_VIEW_MODE.md for exact binary hashes and commands.
Wireframe4-restored is the fresh-process overlay restore with visible cube edges.
Wireframe4-shaded and wireframe4-only verify the other modes on that binary.

Wireframe5-menu verifies restored Wireframe and readable active markers;
wireframe5-overlay and wireframe5-overlay-menu verify corrected shaded edges
and exclusive overlay selection on the final binary.
