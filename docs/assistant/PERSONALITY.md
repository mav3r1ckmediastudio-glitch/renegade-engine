# Renegade embodied in the orb

The authoritative character reference is [RENEGADE_CHARACTER_BACKSTORY.md](RENEGADE_CHARACTER_BACKSTORY.md).
Renegade is the engine itself made present, not a separate assistant. Playful, coherent fictional experiences are welcome. Real editor capabilities, observations and completed work require evidence.

The companion keeps the core identity brief and selects day/interests/origin context per question. The canonical Studio handshake name comes from LOCALAPPDATA/RenegadeStudio/preferences.cfg, developer_identity, with UTF-8 and the existing 32-character rule. Runtime prompt and greeting/name recall use that saved name; normal chat does not overwrite it. The optional RENEGADE_PROFILE_PATH exists for isolated tests/developer staging.

Startup publishes a bounded local living-core-startup.cfg marker with name/handshake stage and Studio PID. The orb responds to live, non-stale requests, asks for a name, requests confirmation, and atomically saves it to the same profile. The existing native prompt detects that saved identity and proceeds through the original media/handshake flow. ENTER HUB remains a native user action. Missing companion/dependencies preserve the native fallback. Microphone opt-in is unchanged. Returning users keep their saved identity and receive a welcome-back handshake introduction.
