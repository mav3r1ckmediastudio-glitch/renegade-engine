# Character V4 continuation experiment — 14 October 2026

Decision: REJECT AS LIVE REPLACEMENT. Successful training does not mean accepted conversation. Existing V3.1 remains active and unchanged.

The existing V3.1 corpus uses the separate Renegade Assistant identity. This conflicts with the current engine-embodied character design, but the experiment does not establish that identity wording is the sole cause of poor generation.

20 authored four-turn scenarios supplied 64 new training continuations and 16 held-out continuations from four entire scenarios. 64 selected older social/correction examples supplied replay with updated system identity. Final training set: 128 examples. Continued the existing rank-8 V3.1 adapter for 96 steps, accumulation four, learning rate 2e-5, max length 768; exact chat-template label boundaries checked. Training completed in 387.5 seconds with average loss 2.6414. These loss numbers are not directly comparable with the older run's different dataset.

Evaluation: 46 generated replies, 23 per adapter. Same quantized base, runtime persona, sampling settings and per-turn seeds. Four held-out dialogue scenarios plus unseen day/fiction and identity/name/control probes. Each adapter followed its own generated history; expected answers were never fed to it. Review considered the model's actual preceding story rather than requiring it to reproduce the authored reference story. Follow-ups mentioning a keeper or original row may not fit a different generated story, so these are not reliable standalone correctness scores.
