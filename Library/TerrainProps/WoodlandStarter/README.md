# Woodland Starter

Import any of the 29 GLB models in Models as a static model and select it in Terrain Props. The files use metres and +Y up. The root marks the ground under the trunk or the centre of the footprint. catalog.json gives each prop's measured X, Y and Z dimensions, creator, license and source record.

The 23 entries with a Detail/LOD2 file have independently loadable distant geometry. Import that file separately and assign it to the terrain profile's distant representation. Detail/LOD1 supplies intermediate geometry. The silver birch coppice has two stems sharing mesh and materials.

Originals preserves the provider files and the source art used to make the pack. The three leaf-litter textures and their generator are in Originals/oak-leaf-litter. Notices contains the license texts and credits. Retain the notices with redistributed assets.

The separate native sample project uses 29 terrain profiles, with four saved authoring mixes. Its project-specific model IDs are recorded for reference. Other projects assign their own IDs at import.
