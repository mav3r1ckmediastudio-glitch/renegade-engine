RENEGADE PHASE 2 DISPLAY GATE
================================

This is a temporary engineering check, not the production Renegade UI.

1. Double-click Run-RenegadeStudio-DX12.cmd.
2. Confirm the title ends with [DX12].
3. Confirm the device, resolution, logical size, color space, and FPS appear.
4. Resize the window and move it between displays or scaling levels if possible.
5. Select the cube, drag the gizmo, edit a transform field, and use Undo/Redo.
6. Use Save As, make another edit, and use Reopen.
7. Close Studio.
8. Double-click Run-RenegadeStudio-Vulkan.cmd.
9. Confirm the title ends with [Vulkan] and repeat selection and gizmo input.

If Windows HDR is available, enable it before a DX12 run and confirm the
reported color space changes without making the UI unreadable.

Report the first failed numbered step, or report:

DX12 PASS / VULKAN PASS / DPI PASS / INPUT PASS / HDR PASS OR NOT AVAILABLE
